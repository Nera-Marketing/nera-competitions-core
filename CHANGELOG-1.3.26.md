# Nera Competitions Standard 1.3.26

## Feature — Remaining attribution copy is ACF-editable

Attribution Page Editor now covers the last hardcoded strings on the
Nera Marketing attribution page. Parent defaults stay competition
wording; raffle sites set copy in admin.

- **Hero:** heading (last line primary colour), intro prefix
  (`[site-name]`), two meta lines, page title (browser tab + WebPage
  schema name).
- **Profile:** fact labels (Location, Specialisation, Services,
  Clients, Build Type, Website).
- **CTA:** decorative watermark text.
- **Schema:** WebPage description (`[site-name]`). Organization and
  Service JSON-LD are unchanged.
